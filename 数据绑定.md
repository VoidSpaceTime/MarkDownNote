# 控件之间绑定
## 直接绑定控件的元素 
### 双向绑定
- ElementName 绑定元素名称
- Path 绑定路径

``` xaml
    <Grid >
        <StackPanel>
        <Slider x:Name="slider"                Margin="5" />
        <TextBox Text="{Binding ElementName=slider,Path=Value}" x:Name="text1" Margin="5" Height=" 20"/>
        <TextBox Text="{Binding ElementName=slider,Path=Value}"                 x:Name="text2"                 Margin="5"                 Height="20" />
        <TextBox Text="{Binding ElementName=slider,Path=Value}"                 x:Name="text3"                 Margin="5"                 Height="20" />
        </StackPanel>
    </Grid>
```

### 绑定模式
```xaml
          <TextBox Text="{Binding ElementName=slider,Path=Value,Mode=OneTime}"
                   x:Name="text1"
                   Margin="5"
                   Height=" 20" />
```
- 增加 mode 属性 

| 模式             | 效果        |
| -------------- | --------- |
| Default        |           |
| OneTime        | 只绑定第一次赋值  |
| OneWay         | 绑定控件->控件  |
| OneWayToSource | 绑定控件<-控件  |
| ToWay          | 绑定控件<->控件 |

# Command
```C#
    //
    // 摘要:
    //     Defines a command.
    [TypeConverter("System.Windows.Input.CommandConverter, PresentationFramework, Version=4.0.0.0, Culture=neutral, PublicKeyToken=31bf3856ad364e35, Custom=null")]
    [ValueSerializer("System.Windows.Input.CommandValueSerializer, PresentationFramework, Version=4.0.0.0, Culture=neutral, PublicKeyToken=31bf3856ad364e35, Custom=null")]
    public interface ICommand
    {
        event EventHandler? CanExecuteChanged; // 事件句柄
        bool CanExecute(object? parameter); // 委托 执行条件
        void Execute(object? parameter);  // 委托 执行函数
    }
```
